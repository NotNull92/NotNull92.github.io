# Project book sources

The English copy in `assets/project-records.js` is an editorial summary of the project owners’ local documentation, inspected on 2026-09-15. The numbered pages are thematic chapters, not dated development diary entries. Both projects remain **In development**.

## Source boundary

The adjacent `golemsculptor` and `monstel` working copies supplied sufficient primary material; no GitHub API access or external research was needed. Paths below are relative to those repositories, not links loaded by the website. Internal source documents are not bundled with the product.

Only broad mechanics, documented design questions, and established art principles are summarized. No device identifiers, private discussion, internal issue reports, unreleased story revelations, release dates, balance numbers, or future platform promises are copied. The website links only to the approved studio Discord; repository accessibility is not assumed.
